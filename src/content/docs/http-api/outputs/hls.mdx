An output type that allows streaming video and audio from Smelter over HLS.

## Usage

To use HLS Output you need to register it first.

<CollapsibleDetails summaryTitle='Example request' open>

```http
POST: /api/output/:output_id/register
Content-Type: application/json

{
  "type": "hls",
  "path": "./output.m3u8",
  "video": {
    "resolution": { "width": 1280, "height": 720 },
    "encoder": { "type": "ffmpeg_h264" },
    "initial": {
      "root": {
        "type": "view"
      }
    }
  },
  "audio": {
    "encoder": { "type": "aac" },
    "channels": "stereo",
    "initial": {
      "inputs": [{ "input_id": "input_1", "volume": 1 }]
    }
  }
}
```
</CollapsibleDetails>

See [HTTP Routes](/http-api/routes#outputs-configuration) documentation to learn more about managing outputs.

## Reference

<CollapsibleDetails summaryTitle='Type definitions' open>

```tsx
type HlsOutput = {
  type: "hls";
  path: string;
  max_playlist_size?: number;
  video?: VideoOptions;
  audio?: AudioOptions;
  ffmpeg_options?: Map<string, string>;
  start_at_ms?: number;
}
```
</CollapsibleDetails>

## Properties

### path
Path to the output HLS playlist file.

- **Type**: `string`

---

### max_playlist_size
Number of segments kept in the playlist. When the limit is reached the oldest segment is removed.
If not specified, no segments will removed.

- **Type**: `number`

---

### video
Video track configuration.

- **Type**: [`VideoOptions`](#videooptions)

---

### audio
Audio track configuration.

- **Type**: [`AudioOptions`](#audiooptions)

---

### ffmpeg_options

Raw FFmpeg muxer options. Visit <a href='https://ffmpeg.org/ffmpeg-formats.html' target='_blank'>FFmpeg docs</a>
to learn more. For codec specific options see `ffmpeg_options` in [`VideoEncoderOptions`](#videoencoderoptions).
Keys set here may override defaults, including `hls_list_size` derived from [`max_playlist_size`](#max_playlist_size).

- **Type**: `Map<string, string>`

---

### start_at_ms
Time in milliseconds when this output should start producing data. Value `0` represents time of
[the start request](/http-api/routes#start-request), same as in
[`schedule_time_ms`](/http-api/routes#update-output). Output is always created when this request is
handled (e.g. playlist is created), only the moment it starts receiving frames/samples is delayed.

- **Type**: `number`

## AudioOptions
<CollapsibleDetails summaryTitle='Type definitions' open>

```tsx
type AudioOptions = {
  mixing_strategy?: "sum_clip" | "sum_scale";
  encoder: AudioEncoderOptions;
  channels?: "mono" | "stereo";
  initial: { inputs: InputAudio[]; };
}
```
</CollapsibleDetails>

### Properties

#### mixing_strategy
Specifies how audio should be mixed.

- **Type**: `"sum_clip" | "sum_scale"`
- **Default value**: `"sum_clip"`
- **Supported values**:
  - `sum_clip` - First, the input samples are summed. If the result exceeds the i16 PCM range, it is clipped.
  - `sum_scale` - First, the input samples are summed. If the result exceeds the i16 PCM range, the summed samples are scaled down by a factor to fit within the range.

---

#### encoder
Audio encoder options.

- **Type**: [`AudioEncoderOptions`](#audioencoderoptions)

#### channels
Channels configuration

- **Type**: `"mono" | "stereo"`
- **Default value**: `"stereo"`
- **Supported values**:
  - `mono` - Mono audio (single channel).
  - `stereo` - Stereo audio (two channels).

#### initial
Initial audio mixer configuration for output.

- **Type**: `{ inputs: InputAudio[]; }`

## InputAudio
<CollapsibleDetails summaryTitle='Type definitions' open>
```tsx
type InputAudio = {
  input_id: string;
  volume?: f32;
}
```
</CollapsibleDetails>

### Properties

#### input_id
ID of an input. It identifies a stream registered using a [register input](/http-api/routes#register-input) method.

- **Type**: `string`

#### volume
Input volume in range `[0, 2]`

- **Type**: `f32`
- **Default value**: `1.0`
- **Supported values**: `[0, 2]`
