## Low latency streaming

WHIP, WHEP and MoQ outputs use low latency settings by default. B-frames are disabled with `"bf": "0"`, and depending on the encoder:

- **libx264**: `"tune": "zerolatency"` also disables frame lookahead and other internal buffering, so every frame is emitted as soon as it is encoded instead of being held back by several frames. Costs some compression efficiency.
- **h264_videotoolbox**: `"realtime": "1"` hints that encoding should happen in real time, keeping up with the rate frames arrive at. It's a hint to VideoToolbox, not a guarantee.

Other outputs don't use these settings, but you can enable them via [`ffmpeg_options`](#ffmpeg_options). If you don't want the full `"tune": "zerolatency"` on libx264, you can set only some of the options it includes:

- `"bf": "0"`: disables B-frames.
- `"rc-lookahead": "0"`: disables frame lookahead, which otherwise adds 30 frames of latency with `"preset": "fast"`.
- `"thread_type": "slice"`: encodes slices of each frame in parallel. Otherwise encoding is parallelized across frames, which delays output by roughly one frame per thread.

## Hardware with high CPU core count

By default, libx264 picks its thread count based on the number of logical CPU cores: 1.5x the number of cores, up to a limit (e.g. 34 for 1080p).

Spawning unnecessary threads can cause higher CPU contention and memory usage. It also adds roughly one frame of latency per thread, unless `"thread_type": "slice"` is set. To use fewer threads, set `threads` in [`ffmpeg_options`](#ffmpeg_options).

## Encoder selection

By default, FFmpeg picks whichever H.264 encoder is available in the build it was compiled with. Use [`encoder_name`](#encoder_name) to select a specific one. Smelter passes a different set of default options depending on which encoder was picked. Anything you set in [`ffmpeg_options`](#ffmpeg_options) is applied on top of these defaults and overrides them.

<CollapsibleDetails summaryTitle='libopenh264'>

Default options:

```jsonc frame=none
"qmin": "4",      // minimum QP
"qmax": "51",     // maximum QP, increased vs the encoder default to allow
                  // low bitrates without dropping frames
"threads": "0",   // auto-detect thread count
"b": "...",       // average bitrate, from "bitrate" or calculated
                  // from resolution and framerate
"maxrate": "...", // maximum bitrate
"g": "...",       // GOP size in frames, from "keyframe_interval_ms"
"bf": "0",        // ONLY for WHIP, WHEP and MoQ outputs, disable B-frames
```

</CollapsibleDetails>

<CollapsibleDetails summaryTitle='h264_videotoolbox (macOS only)'>

Default options:

```jsonc frame=none
"qmin": "4",      // minimum QP
"qmax": "51",     // maximum QP, increased vs the encoder default to allow
                  // low bitrates without dropping frames
"b": "...",       // average bitrate, from "bitrate" or calculated
                  // from resolution and framerate
"maxrate": "...", // maximum bitrate
"g": "...",       // GOP size in frames, from "keyframe_interval_ms"
"bf": "0",        // ONLY for WHIP, WHEP and MoQ outputs, disable B-frames
"realtime": "1",  // ONLY for WHIP, WHEP and MoQ outputs
```

</CollapsibleDetails>

<CollapsibleDetails summaryTitle='libx264'>

Default options:

```jsonc frame=none
"preset": "fast",      // x264 encoding preset
"g": "...",            // GOP size in frames, from "keyframe_interval_ms"
"crf": "23",           // ONLY if "bitrate" is not set, quality-based VBR
"b": "...",            // ONLY if "bitrate" is set, average bitrate
"maxrate": "...",      // ONLY if "bitrate" is set, maximum bitrate
"bufsize": "...",      // ONLY if "bitrate" is set, equal to the average bitrate
"tune": "zerolatency", // ONLY for WHIP, WHEP and MoQ outputs
"bf": "0",             // ONLY for WHIP, WHEP and MoQ outputs, disable B-frames
```

Other outputs use B-frames whenever the preset enables them (3 for `fast`). To disable them, set `"bf": "0"` in [`ffmpeg_options`](#ffmpeg_options).

To use a different preset, set it in [`ffmpeg_options`](#ffmpeg_options), e.g. `"preset": "ultrafast"`. See the <a href='https://trac.ffmpeg.org/wiki/Encode/H.264#Preset' target='_blank'>FFmpeg docs</a> for available values.

</CollapsibleDetails>

<CollapsibleDetails summaryTitle='Other encoders'>

Default options:

```jsonc frame=none
"g": "...",       // GOP size in frames, from "keyframe_interval_ms"
"b": "...",       // ONLY if "bitrate" is set, average bitrate
"maxrate": "...", // ONLY if "bitrate" is set, maximum bitrate
"bf": "0",        // ONLY for WHIP, WHEP and MoQ outputs, disable B-frames
```

</CollapsibleDetails>

## Reference

```tsx
type FfmpegH264EncoderOptions = {

    | number
    | {
      average_bitrate: number;
      max_bitrate: number;
    };

  pixel_format?: "yuv420p" | "yuv422p" | "yuv444p";
  ffmpeg_options?: Record<string, string>;
};
```

## Properties

### encoder_name

Name of the FFmpeg encoder to use, e.g. `"libopenh264"`. It must be an H.264 encoder available in the FFmpeg installed on the system.

- **Type**: `string`
- **Default value**: The H.264 encoder that FFmpeg selects by default.

---

### bitrate

Desired bitrate of the output stream, in bits per second. If only a number is specified then it defines the [`average_bitrate`](#average_bitrate).
The [`max_bitrate`](#max_bitrate) is then set to 1.25x this value.

- **Type**: `number | { average_bitrate: number; max_bitrate: number; }`
- **Default value**: Dependent on the encoder used:
  - **libx264**: Constant quality mode with the `crf` equal to 23.
    Visit [FFmpeg docs](https://trac.ffmpeg.org/wiki/Encode/H.264#crf) to learn more.
  - **libopenh264**, **h264_videotoolbox**: Calculated based on framerate and resolution. Eg. for 30 FPS in 1080p
     the `averageBitrate` would be 5000 kb/s and `maxBitrate` 6250 kb/s.
  - **Other encoders**: Default of the encoder.

---

#### Properties

##### average_bitrate

Average bitrate measured in bits per second. Encoder will try to keep the bitrate around the provided average, but may temporarily increase it to the provided max bitrate.

- **Type**: `number`

--- 

##### max_bitrate

Max bitrate measured in bits per second.

- **Type**: `number`

---

### keyframe_interval_ms

Maximal interval between 2 consecutive keyframes, in milliseconds.

- **Type**: `number`
- **Default value**: `5000`

---

### pixel_format

Encoder pixel format.

- **Type**: `"yuv420p" | "yuv422p" | "yuv444p";`
- **Default value**: `yuv420p`
- **Supported values**: Dependent on the encoder used:
  - **libx264**: `yuv420p`, `yuv422p`, `yuv444p`
  - **libopenh264**: `yuv420p`
  - **h264_videotoolbox**: `yuv420p`

---

### ffmpeg_options

Raw FFmpeg encoder options. Visit <a href='https://ffmpeg.org/ffmpeg-codecs.html' target='_blank'>FFmpeg docs</a> to learn more.

- **Type**: `Record<string, string>`
